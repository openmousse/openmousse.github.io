功能

Zen

先把想法记下而不触发回复，准备好后再与 AI 推敲，将成熟的观点写入世界树。

在 OpenMousse app 底栏打开第二格「Zen」（底栏依次为「对话 / Zen / 今天 / 目标」）即可记录想法与展开推敲。

Zen 是先把想法放下的地方。一篇刚读完的文章、一段印象深刻的视频，或一闪而过的念头，都可以先存入 Zen。存入不会触发回复，AI 不会介入；等你准备好之后，再挑出相关内容与 AI 一起推敲，将成熟的观点写入世界树，在之后的决策里发挥作用。

如何使用 Zen

Zen 的使用分为四个步骤，每一步是否让 AI 介入均由你决定：

  1. 1.记下想法（只存不发）：随手记下的想法以 Markdown 笔记的形式保存在你的服务器或你的笔记库中。此时内容只存不发——不会发给模型，不会进入任何 Agent 的记忆，也不会在凌晨 03:45 日结时自动写入世界树。
  2. 2.「讨论」与「只记下」：当你准备好推敲时，挑出几条想法点击「讨论」，即可与 AI 一起梳理和讨论。在聊的过程中，如果你临时想到一句话但不想让 AI 接着往下接，可以点击「只记下」：这句话只保存在笔记里，不发给 AI 看。
  3. 3.完成：讨论告一段落时，点击「完成」，AI 会将这次思考的过程与结论整理成一份笔记草稿供你审阅和修改。
  4. 4.保存到库：你改好草稿后点击「保存到库」。其中值得长期记住的成熟观点会写成世界树的叶子，需要执行的待办事项则会加进你的日程。
i
提示：Zen 的隐私与模型调用边界

只要你不点击「讨论」，你在 Zen 里写下的任何文字都只留在你的服务器本地（或你的同步笔记库中），不会产生任何发往模型服务的请求。

不在这里的东西

  • •未经「保存到库」的内容不进世界树：在主对话或功能 Agent 对话中说出的个人偏好与决定，会被直接（或在 03:45 日结时）写进世界树；但在 Zen 中，只有走完「讨论 → 完成 → 保存到库」这一步的内容，才会写入世界树与日程。
  • •不是任务看板或资料原文库：长期跟踪的项目表格与日历存放在各功能 Agent 的看板中；课程、文件与阅读材料的原文则存放在「学习与办公 Agent」的资料库中。

Features

Zen

Capture thoughts without triggering AI replies, refine them when ready, and save distilled opinions to the memory tree.

Open Zen from the second tab of the bottom bar in the OpenMousse app (Chats / Zen / Today / Goals) to jot down thoughts and refine them.

Zen is a place to set thoughts down first. An article you just finished, a video that stood out, or a passing idea can all go into Zen first. Saving a note does not trigger a reply and the AI does not step in; when you are ready, pick out related notes to refine with the AI and save distilled opinions to the memory tree so they can inform future decisions.

How to use Zen

Using Zen follows four steps, and at every step you decide whether the AI is involved:

  1. 1.Capture thoughts (saved without sending): Thoughts you jot down are saved as Markdown notes on your server or in your note vault. At this stage, content is saved without being sent—it is not sent to any model, does not enter any agent's memory, and is not automatically written to the memory tree during the 03:45 settlement.
  2. 2.Discuss and private note: When you are ready to think something through, select a few notes and tap Discuss to organize and discuss them with the AI. During the discussion, if a thought occurs to you that you do not want the AI to respond to, tap private note: the line is saved only in the note and is not shown to the AI.
  3. 3.Done: When the discussion wraps up, tap Done and the AI compiles the thinking process and conclusions into a draft note for you to review and edit.
  4. 4.Save to the vault: Once you finish editing the draft, tap Save to the vault. Distilled opinions worth keeping long term are written as leaves in the memory tree, and action items that need to be carried out are added to your schedule.
i
Note: Zen privacy and model call boundaries

As long as you do not tap Discuss, anything you write in Zen stays strictly on your local server (or in your synced note vault) and generates no requests to any model provider.

What stays out

  • •Nothing enters the memory tree unless you tap Save to the vault: Personal preferences and decisions mentioned in main chat or functional agent chats are written to the memory tree directly (or during the 03:45 settlement); in Zen, only content that completes the full Discuss → Done → Save to the vault flow is written to the memory tree and your schedule.
  • •Not a task board or source document library: Long-running project tables and calendars live in each functional agent's board; the full text of courses, documents, and reading materials lives in the Study & Work agent's library.

See also

  • •Memory Tree: Learn how distilled opinions saved via Save to the vault become leaves in the memory tree that other agents can recall.
  • •Today View and 04:00 Settlement: Learn how action items saved to the vault appear in your schedule, and what is excluded from the 03:45 settlement.
