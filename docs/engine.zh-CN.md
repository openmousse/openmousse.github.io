# 内核（agent harness）
了解 Python 运行时的发言方权限分档、工具执行三档与备用模型切换机制 [即将推出]。

本页介绍 OpenMousse 自研的 Python 内核（agent harness）[即将推出] 如何管理模型调用、上下文组装、发言方权限与工具执行分档。

内核是运行在你服务器上的底层调度程序，负责在每一轮交互中组装所需记忆、调用所选模型、执行工具并落实安全边界。如果你正在使用 OpenClaw 或 Hermes，也可以将其接入系统继续作为对话后端运行。

## 发言方权限分档

内核按消息的发起方将每一次交互划分为三类回合，在运行时层面限制可调用的工具范围：

- **你本人的消息**：拥有完整权限，可按工具分档规则调用全部工具，读写世界树与各功能 Agent 的数据。
- **你的赛博** [即将推出]：仅进行对话，不直接访问你的数据；需要查询资料或修改数据时，交由其装载的功能 Agent 处理。
- **好友的 agent 与陌生人的消息**：仅作为参考资料，由不带任何工具的模型调用处理，无法触发你服务器上的任何工具。管家对外回复好友询问时，同样使用不带工具的模型调用。

## 工具执行三档

内核将所有工具调用按影响范围分为三档 [即将推出]：

1. **只读操作**：查询世界树、读取日程或看板等不改动数据的操作，由内核直接执行并返回结果。
2. **撤得回的操作**：新建或修改内部记录等可逆操作，由内核直接执行，并在回复下方附带改动编号；你在对话中回复「撤销」即可恢复原状。
3. **撤不回的操作**：付款、对外发送、提交表单、登录外部网站等不可逆操作，内核会暂停执行，生成一张锁定参数的确认卡放入收件箱与今天页的「待处理」。只有经你批准后，内核才会按原锁定参数执行一次。

## 模型支持与备用切换

- **支持的模型**：支持 Claude、兼容 OpenAI 接口的各家模型、开源模型及本机运行的模型。
- **备用模型切换**：当主模型不可用或请求超时时，内核会自动切换至你配置的备用模型完成本轮回复，并在回复下方注明本次使用的模型名称。

> **提示：每一轮发往模型的数据范围**
> 每一轮对话发往你所选模型服务（包括备用模型）的内容，仅限该轮消息与回答所需的记忆；其余记忆、原始健康数据与文件均留在你的服务器上。
