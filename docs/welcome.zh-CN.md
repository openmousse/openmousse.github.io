# 欢迎使用 OpenMousse
了解 OpenMousse 的核心组件、数据归属与运行边界。

![主对话里的会议纪要，和手机上的「今天」](https://openmousse.ai/docs/assets/welcome.zh-CN.png)

OpenMousse 是开源的个人 AI agent 系统（AGPL-3.0）。你的对话、日常数据、工作与学习资料以及好友间的讨论均保存在只属于你的服务器上，从中提炼的事实、偏好、决定与成熟的观点沉淀为长期记忆（世界树）。多个功能 Agent 在此基础上，按你原有的工作方式负责安排、提醒与代办。

系统运行在你的自有服务器上，也可以运行在我们即将开放的托管专属云服务器上（可在官网首页加入等候名单）。客户端提供 iPhone（TestFlight 邀请）、Android（安装包）与网页版；电脑端（网页工作台与 Mac 客户端）即将推出。

## 你会得到什么

- **可查阅、可修改的世界树。** 每一条关于你的事实、偏好、决定与观点都存为一片带出处的叶子，标明来自哪一次对话、哪一天。你可以随时查看、修改或删除，也可以将其存为 Markdown 笔记放入自己的笔记库。
- **跨 AI 应用共用的长期记忆。** Claude、ChatGPT、Gemini、Notion 与 Claude Code 可通过各自的专属地址接入世界树，回答前先调取你的背景，并将新信息写回世界树，不再各存一份。
- **职责分明的功能 Agent 与会议。** 主对话是总入口，负责把事务转交给健身、饮食、睡眠、代办、学习与办公等功能 Agent，或召集它们开短会并出具纪要；每个功能 Agent 拥有独立的记忆、工具与看板（支持表格、看板、日历、时间线、图表五种视图）。
- **先放下想法的 Zen。** 刚读完的文章或一闪而过的念头可以先存入 Zen，只存不发，AI 不会介入；准备好之后再挑出相关内容点「讨论」一起推敲，点「完成」整理并「保存到库」，成熟的观点写入世界树。
- **撤不回的操作先问你。** 付款、对外发送、提交、登录等操作一律先停下来，生成锁定参数的确认卡放入收件箱与今天页的「待处理」，等你批准后才执行。
- **隔离的代办沙箱与 Doorman。** 代办 Agent 在隔离的沙箱中打开网页、比价、填表与预订；密码由 Doorman 保管，代办只拿到占位符，请求离开服务器的那一刻才换成真值并发往绑定的网站。
- **有边界的好友互动与管家。** 好友消息经签名并端到端加密；对外分享的讨论先逐条遮盖隐私；管家按亲近、朋友、同学三档关系回答忙闲与近况，看不到世界树与健康数据，涉及时间、金钱、承诺的事一律生成确认卡交给你定。
- **长期辅助思考的赛博** [即将推出]**。** 赛博拥有独立的性格、记忆与模型，在特定方向上长期辅助你思考；它不直接访问你的数据，查资料或改动数据均交由其装载的功能 Agent 处理。

> **提示：OpenMousse 的边界与承诺**
> OpenMousse 不会在未经你确认的情况下对外发信、付款或承诺时间。我们不投放广告，不出售数据，不用你的数据训练模型。每一轮对话发往你所选模型服务（包括备用模型）的内容，仅限该轮消息与回答所需的记忆；其余记忆与文件均留在你的服务器上。
