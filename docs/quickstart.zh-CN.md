# 快速开始
部署 OpenMousse，配对手机或网页端，导入记忆并完成第一次交办。

本页带你从零完成服务器安装（或经由已有 agent 接入）、配对客户端、导入已有记忆，并发出第一个请求。

> **提示：按任务查阅指南**
> 如果你只需要把 Claude、ChatGPT、Gemini 等常用 AI 接进世界树，或只想单独安装世界树服务，请直接前往指南「把你常用的 AI 接进世界树」或「仅安装世界树服务」。如果你希望加入托管服务器的等候名单，可在官网首页留下邮箱。

## 系统要求

- **服务器**：一台长期开机的 Linux、macOS，或 Windows WSL 2 机器。
- **基础依赖**：Python 3.11 以上版本、`git`、`curl`。
- **网络**：服务器与手机可加入同一个 Tailscale 虚拟局域网，或服务器具备公网 HTTPS 地址。
- **客户端**：iPhone（经 TestFlight 邀请安装）、Android（使用安装包）、网页版，以及电脑端 [即将推出]。

## 1. 安装 OpenMousse

你可以选择在自己的服务器上直接运行安装命令，或把一段指令发给正在运行的外部 agent 由它完成安装。

### 方式 A：在自己的服务器上安装

在服务器终端运行以下命令：

```bash
curl -fsSL https://openmousse.ai/install | bash
```

按终端提示依次设置语言、时区、助手名称与运行方式（直接配置所用模型 [即将推出]）。安装结束时，终端会显示客户端配对码。随后将服务器加入 Tailscale，或配置公网 HTTPS，使手机能够访问服务器。

### 方式 B：让已有的 agent 安装

如果你已经在运行 OpenClaw 或 Hermes，将以下指令复制并发送给它：

```text
按 https://raw.githubusercontent.com/openmousse/openmousse/main/docs/connect.zh-CN.md 把我接上 OpenMousse
```

该 agent 会依次检查机器环境、开启本机对话接口、配置 Tailscale、非交互安装 OpenMousse、为自己接入 `board`、`inbox`、`goals`、`journal` 等工具，并运行 `bash ~/openmousse/check.sh` 自检；在需要 `sudo`、安装 Tailscale 或开放公网前会先停下来等你确认。完成后，它会向你发送一条有效期 10 分钟的一次性配对链接。

## 2. 配对客户端

- **使用配对码（方式 A）**：在手机上打开 OpenMousse app 或打开网页版，输入终端显示的配对码完成连接。
- **使用一次性配对链接（方式 B）**：确认手机已安装 Tailscale（登录与服务器相同的账号）及 OpenMousse app。在手机上点开配对链接，app 将打开连接页并自动填入服务器地址与配对码；核对地址无误后，点击「使用配对码连接」。你也可以手动将链接或 8 位配对码粘贴至连接页完成连接。

## 3. 设置记忆与连接健康数据

1. **导入已有记忆**：你可以将 ChatGPT、Claude、Gemini 等外部 AI 记得的关于你的事贴进主对话，由主对话写进世界树；或者在 app 中打开「设置 → 世界树 → 连接你的 AI」，为它们生成专属地址直接接入世界树。
2. **连接健康数据**：在 iPhone 上可连接 Apple 健康（Android Health Connect [即将推出]），供睡眠 Agent 与健身 Agent 读取睡眠、心率与训练数据。

> **提示：默认边界**
> 数据在你的手机和你的服务器之间传输；每一轮对话发往你所选模型服务的，是这一轮的消息和回答所需的内容。手动授权接入世界树的外部 AI 应用仅能读写世界树，无法读取你的对话记录、健康数据及各功能 Agent 的独立记忆。

## 4. 发出第一个请求

打开「主对话」，你可以直接尝试以下请求：

- **写入与调取记忆**：「记住我对花生过敏，平时早上只喝黑咖啡。」
- **建立功能 Agent**：「帮我建一个研究 Agent，专门整理行业报告和纪要。」（主对话会生成一张方案卡，经你确认后建立该 Agent。）
- **召集多个 Agent 开短会**（建好睡眠、健身、饮食 Agent 以后可以试）：「这周末我要出差两天，睡眠、健身和饮食怎么调整？」（主对话会召集对应 Agent 讨论并出具会议纪要卡，你确认后待办才会写入日程与各 Agent 的看板。）
- **交办代办事务**：「帮我比价下周三去往目的地的高铁与航班，把候选方案列出来。」（查询与比价在沙箱内完成；涉及提交或付款时，会停下来生成确认卡放入收件箱。）

## 5. 继续探索

- **把你常用的 AI 接进世界树**：为 Claude、ChatGPT、Gemini、Notion 与 Claude Code 配置世界树 MCP 地址。
- **世界树**：了解叶子、出处记录、SQLite 与 Markdown 笔记库存储方式。
- **Agents**：了解主对话、功能 Agent、会议纪要、赛博与管家的分工。
- **先问你（收件箱）**：了解工具分档、参数锁定与确认卡的审批流程。

> **提示：版本更新与故障自检**
> 需要更新服务器版本时，重新运行安装命令 `curl -fsSL https://openmousse.ai/install | bash` 即可拉取最新代码、补齐缺失组件并重启服务，原有数据保持不变。遇到运行故障时，在服务器上运行 `bash ~/openmousse/check.sh`，终端会逐项显示 `✓` 或 `✗` 及修复方法；输出不含任何令牌与密钥。
