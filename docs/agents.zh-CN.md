# Agents
了解主对话、功能 Agent、会议纪要、群聊、赛博与管家的分工和边界。

在 OpenMousse app 的对话列表中即可查看并进入所有 Agent；列表第一行固定为主对话，其余为各功能 Agent、赛博与群聊。

OpenMousse 将日常事务、长期思考与对外沟通分给不同角色的 Agent 处理。你可以在主对话中交代需求，由主对话转交给对应的功能 Agent 或召集会议；也可以直接点进任意一个功能 Agent 的对话、看板与独立记忆页面与它沟通。

## 各类角色与分工

- **主对话**：系统的总入口。负责接收你的日常交办、读写世界树、向功能 Agent 分派任务，以及发起并主持多 Agent 会议。每晚日结后，主对话也可能把你反复处理的事务提议为新的功能 Agent，生成方案卡放入收件箱等你确认。
- **功能 Agent**：每个功能 Agent 只负责一类事，其中代办 Agent、学习与办公 Agent 默认启用，健身 Agent、饮食 Agent、睡眠 Agent 以及其他领域的 Agent（例如研究 Agent）可按需新建。每个功能 Agent 拥有独立的对话、记忆、工具与看板；看板集合支持五种视图：表格、看板、日历、时间线、图表。
- **赛博** [即将推出]：拥有独立的性格、记忆与模型，在特定方向上长期辅助你思考（例如一位追问到底的质疑者或一位学习教练）。它的资料页是一张证件，仅包含身份、记忆、装载三项。赛博不直接访问你的数据，查资料或改动数据均交由其「装载的功能 Agent」处理：只读结果直接返回，修改数据则生成确认卡，要写进世界树也须先生成确认卡（或进入「待确认」）经你确认。
- **管家** [即将推出]：对外代表你，按亲近、朋友、同学三档关系回答好友及好友 agent 的询问（例如核对周四晚上是否有空）。管家仅读取你按该档位开放的日程、近况、分享过的内容、学习笔记或住址，看不到世界树与健康数据。涉及时间、金钱、承诺的事项，管家一律回答「这个得（你的名字）本人定，我去问一下。」并生成确认卡交给你；每一句对外回复在发出前均经 Doorman 复查。

## 会议、纪要与群聊

- **会议与纪要**：遇到需要跨领域协同的事，可由主对话发起并主持短会，你也可以在 app 内自己发起。会上几个 Agent 轮流发言，每轮每个 Agent 最多发言一次，并可 `@` 其他成员；会上只讨论，不改动任何数据。一轮结束后，主对话出具一张会议纪要卡（包含决定与待办，每条待办标明负责的 Agent 与时间），出现在主对话中。经你确认后，待办才会写入日程与对应 Agent 的看板；你也可以补一句开启下一轮。
- **群聊**：几个 Agent（包括赛博）在一个群内讨论，你 `@` 谁谁回答，不生成会议纪要。会议结束后也可以保留为群聊。

## 不在这里的东西

- **没有日程 Agent 与朋友 Agent**：日程由主对话与各功能 Agent 共用并写入今天页；好友互动与对外回复由「好友」功能及「管家」负责。
- **没有跨用户的 Agent 模板库**：功能 Agent 均在你的服务器上通过主对话方案卡或 app 内表单按需建立。
- **管家不理会陌生人，也不自决承诺**：只有互为好友的联系人能向管家提问；管家回复使用不带任何工具的模型调用，不能自行答应约会或索取请求。
