# 世界树
将事实、偏好、决定与成熟的观点存为带出处的叶子，保存在 SQLite 数据库或 Markdown 笔记库中。

在 OpenMousse app 中打开「设置 → 世界树」即可查看与管理；「世界树」这一行会显示当前的叶子总数（「N 片叶子」），有待确认条目时则显示「N 条待确认」。

世界树（英文界面称 memory tree）是保存在你服务器上的长期记忆。一条记忆是一片叶子，每一片叶子都带有出处，记录它来自哪一次对话、哪一天；开源版的世界树不设「枝」，叶子按来源（写入该叶子的外部平台或 Agent）归类查看。你可以随时查看、修改或删除任意一片叶子。

开源版默认将世界树存在服务器上的 SQLite 数据库中；你也可以将其配置为一条一篇 Markdown 笔记，放进你的笔记库（例如与 Obsidian 同步的文件夹）。安装时若指定了笔记库路径会直接按 Markdown 存储，后续也可以使用 `mousse-tree migrate` 切换存储方式。

在记忆页 [即将推出] 中，年轮外圈是今天，往里是前几天；一个点代表一条新记忆，琥珀点停在环外代表「待确认」。开启「待确认」开关后（该开关目前默认关闭），拿不准的记忆会先进「待确认」，经你确认后才正式写入世界树。此外，系统支持每周日提议合并或删除重复的叶子并交由你逐条确认 [即将推出]。

## Agent 如何使用世界树

- **主对话与功能 Agent**：在平时对话中，当它们得知关于你的新事实、偏好、决定或近况时，会将其写进世界树，并在回答你的问题前先查询世界树。
- **03:45 日结与 04:00 会话重置**：每天 03:45 日结时，各 Agent 会把当天的结论与新知道的关于你的事写进各自记忆和世界树；04:00 会话重置，当天的对话按天归档。
- **赛博** [即将推出]：赛博通过其装载的功能 Agent 读取世界树；若要将内容写进世界树，须先生成一张确认卡（或进入「待确认」），经你确认后才写入。
- **接入的外部 AI 应用**：通过 MCP 接入的 Claude、ChatGPT、Gemini、Notion 与 Claude Code 在回答前调用 `profile` 和 `recall` 读取世界树，并在得知新信息时调用 `remember` 写回世界树。

## 存什么

世界树只存**关于你的事**：你的事实、偏好、决定、近况与成熟的观点。它们来自五个渠道：

1. **其他 AI**：你在 ChatGPT、Claude、Gemini 等外部应用对话中谈及的个人事实、偏好与决定（或初次使用时把它们记得的关于你的事贴进主对话写进世界树的记忆）。
2. **日常结论**：从健康、日程、邮件中得出的关于你的结论（例如「最近睡得少」）。
3. **工作与学习复述**：学习时你用自己的话复述的要点与你的观点。
4. **Zen 中成熟的观点**：在 Zen 里经过「讨论 → 完成 → 保存到库」整理后，值得长期记住的观点。
5. **朋友讨论**：与朋友的讨论或一起录制的播客中提炼出的关于你的观点与决定。

## 不在这里的东西

以下数据虽然也保存在你的服务器上（或留在原处），但**不会**写进世界树，外部接入的 AI 应用也无法通过世界树读取它们：

- **原始健康、日程、邮件与文件数据**：Apple 健康的睡眠、心率、训练明细，以及原始日程表、邮件和文件，由对应的功能 Agent 直接读取，本身不是世界树的叶子。
- **学习时阅读的原文**：课程、文件与阅读材料的原文进入「学习与办公 Agent」的资料库，不进世界树。
- **Zen 里未存进库的想法**：在 Zen 中随手记下的想法，或聊天时点击「只记下」的内容，只存为本地 Markdown 笔记，不发给模型，也不会在凌晨日结时自动写进世界树。
- **外部 AI 平台的完整对话记录**：接入世界树的外部 AI 只把关于你的事写入世界树，完整的聊天上下文仍留在各家平台上。
- **各功能 Agent 的独立记忆与对话记录**：每个功能 Agent 拥有自己的对话、看板与独立记忆，与世界树分开存放。
- **管家的可见范围**：管家对外回答好友询问时，完全看不到世界树，只看你按关系档位明确放出的日程、近况、分享过的内容、学习笔记或住址。
