# 路线图
查看正在开发与即将上线的功能模块。

本页列出 OpenMousse 正在合入主分支、已在内部实例运行或已完成方案设计的功能模块。各模块按当前所处阶段分组列出，测试完成后依次进入公开仓库。

> **提示：关于发布节奏**
> 本页仅反映工程进度与已确定的产品方案，不设固定发布日期。已上线的功能请参阅左侧目录中的「功能」与「指南」各页。

## 正在合入与内部运行

以下模块已在开发分支实现，或在内部实例中稳定运行，正在整理合入公开主分支（`main`）：

- **自研 Python 内核（agent harness）** [即将推出]：负责模型调用、上下文管理与安全规则执行。包含按发言方划分的三类权限回合（本人、赛博、好友的 agent 与陌生人）、工具执行三档（只读直接执行、撤得回附带改动编号并支持回复「撤销」恢复、撤不回生成锁定参数的确认卡），以及主模型不可用时自动切换备用模型并注明。
- **程序调用接口** [即将推出]：在内核中提供兼容 OpenAI 的 API 与 ACP 协议，支持代码编辑器及其他外部程序将 OpenMousse 作为模型直接调用。
- **世界树每周修剪** [即将推出]：每周日自动排查重复或相近的世界树叶子，提议合并或删除，并交由你逐条确认后生效。
- **Agent 编写的隔离页面** [即将推出]：运行在隔离环境中，无法读取登录凭证与其他系统数据，也无法向外部发送数据；首次打开时列出所需读取的数据项，经你同意后仅作只读访问，代码更新后需重新确认。

## 方案已定，正在开发

以下模块已完成交互与架构方案设计，正在推进客户端或服务端开发：

- **电脑端与 Android 健康接入**：推出电脑端（网页工作台与 Mac 客户端）；在 Android 客户端支持接入 Health Connect 读取睡眠、心率与训练数据。
- **托管专属云服务器**：提供官方托管的专属云服务器选项，当前可在官网首页加入等候名单。
- **记忆页与年轮视图**：客户端底栏第四格更新为「记忆」，世界树移入其中。新增年轮视图：外圈为今天，向内为过往日期；每个点代表一条新记忆，停在环外的琥珀点代表等待你确认的条目。
- **赛博（长期思考辅助）**：拥有独立性格、记忆与模型的 Agent，在特定方向上长期辅助思考。资料页为一张包含「身份、记忆、装载」三项的证件；赛博不直接访问你的数据，查询资料与执行操作均交由其装载的功能 Agent 完成，修改数据或写入世界树须经确认卡批准。
- **管家（由「名片 Agent」升级）**：对外代表你，按亲近、朋友、同学三档关系回答好友及好友管家的询问；仅读取对应档位开放的信息，看不到世界树与健康数据，涉及时间、金钱与承诺的事项一律交由你本人决定，且每句对外回复均经 Doorman 复查。
- **交互式新建 Agent 流程**：支持「一句话描述 → 系统补问 → 预填草稿 → 试聊满意后再正式建立」的创建方式。
