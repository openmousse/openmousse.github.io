# 数据与安全
查看数据存储位置、按设计会离开服务器或由客户端发出的请求范围，以及外部应用的隔离边界。

数据隔离、工具权限分档与 Doorman 出网管控在你的 OpenMousse 服务器上默认开启，无需额外配置；你也可以在服务器上随时运行 `bash ~/openmousse/check.sh` 检查各项服务的运行状态。

OpenMousse 的设计原则是将数据留在只属于你的服务器上，并严格限制每一次出网请求与外来信息的权限。我们不投放广告，不出售数据，不用你的数据训练模型；全部核心代码以 AGPL-3.0 协议开源。

## 数据存储在哪里

你的对话记录与附件、世界树（SQLite 数据库或 Markdown 笔记库）、Zen 笔记、Apple 健康每日汇总，以及各功能 Agent 的独立记忆与看板数据，全部存储在只属于你的服务器上（你自备的机器，或我们托管的专属云服务器）。

- **访问权限**：上述数据仅供你已配对的客户端设备，以及你服务器上的各 Agent 按各自权限读取。
- **外部 AI 应用的隔离**：你通过 MCP 手动授权接入世界树的外部 AI 应用（Claude、ChatGPT、Gemini、Notion、Claude Code）仅能读写世界树，无法读取你的对话记录、健康数据及各功能 Agent 的独立记忆。
- **托管服务器访问政策**：如果你使用我们托管的专属云服务器，只有当你为排查故障明确授权时，运维人员才会登录你的服务器，并留下你能随时查看的操作记录。

## 什么数据会离开你的服务器

按设计会离开你的服务器（或由客户端发出）的内容包括：

| 目标服务 | 发送的数据范围 | 边界与说明 |
| --- | --- | --- |
| **模型服务** | 每一轮的消息与回答所需的记忆 | 发往你在 OpenClaw 中配置的模型服务商（如 Anthropic、OpenAI、Google，含备用模型），使用你自己的账号；其余的世界树叶子、历史对话与本地文件留在你的服务器上，Zen 中未点击「讨论」的想法不发给模型。 |
| **推送通知（Expo、Apple）** | 简短的通知标题与预览 | 经 Expo 推送服务与 Apple 推送服务发送；对话回复的通知包含对话名与回复的前 140 个字。 |
| **语音转写** | 语音消息与当面播客录音的音频 | 由服务器配置的转写服务处理：默认使用 OpenAI，也可换成你自己的 Whisper 兼容服务；播客录音同样走你所选的转写服务，转写后的原话与纪要保存在发起人自己的服务器与 app 中。 |
| **接入世界树的 AI 应用（可选）** | 世界树的读写内容 | 如果你将 Claude.ai、ChatGPT、Gemini 或 Notion 等应用接入世界树，这些服务会通过你设置的地址读写世界树。 |
| **连接器（可选）** | 对所连接应用的读写请求 | 在「设置 → 连接器」中接入 Notion 这类应用后，登录令牌保存在你的服务器上，由你的 claw 经你的服务器读写该应用。 |
| **营养查询（Open Food Facts、USDA FoodData Central）** | 食物名称或条码 | 记录饮食时，若某样食物不在你自己的食物库中，服务器会向上述服务查询；请求中仅含食物名称或条码，不含你的任何个人信息，查询结果缓存在你的服务器上。 |
| **分享链接与好友消息（可选）** | 分享内容快照、私聊消息、分享卡，或经 Doorman 复查通过的管家回复 | 分享链接向持有链接的人展示选中内容的快照（住址、家人名字等私事显示为灰条）。好友服务器之间互发带签名、端到端加密的消息；无公网地址时经 OpenMousse 中继（`relay.openmousse.ai`，运行于 Cloudflare）转发，中继仅见收件服务器地址、大小与时间，读不到内容也不保存（Cloudflare 可能保留 IP 地址等常规访问记录）。 |
| **代办访问的网站（经 Doorman）** | 网页浏览、比价与表单请求 | 代办 Agent 在隔离沙箱中运行；真实密码由 Doorman 在请求离开服务器的那一刻替换占位符，且只发往绑定的目标网站；提交、登录与付款均须先经你批准。 |
| **TestFlight 版的账号（Supabase 欧盟区、Resend）** | 邮箱、可选的名字，以及连过的 claw 列表 | 仅 TestFlight 版需邮箱验证码登录（验证码邮件由 Resend 发出，账号存于 Supabase 爱尔兰区，保留登录时间与 IP 等常规记录）。记录的 claw 信息仅含助手名、服务器地址、claw 类型与名字、最近在线时间；从不存储令牌、对话、记忆、健康数据与连接器凭据。网页版与自行构建的版本无账号。 |
| **app 更新查询（Expo）** | app 与系统版本信息 | app 向 Expo 更新服务查询新版本代码，请求中仅含版本信息，不含你的任何内容。 |

## 发言方权限与外来信息隔离

系统内核按发言方将交互严格分为三类回合，并对工具实行三档管控 [即将推出]：

- **你本人的消息**：可调用全部工具（只读直接做；撤得回的直接做并附改动编号，回「撤销」即可恢复；撤不回的出确认卡并锁定参数，等你批准后按原参数执行一次）。
- **你的赛博** [即将推出]：仅进行对话，不直接访问数据；查询或修改数据均须交由其装载的功能 Agent 处理。
- **好友的 agent 与陌生人的消息**：不能调用任何工具。陌生人默认一律不理；好友的 agent 发来的话仅作为参考资料，由不能使用任何工具的模型调用处理；外部网页内容则仅由沙箱内的代办 Agent 读取。
- **Agent 编写的页面** [即将推出]：运行在隔离环境中，读不到登录信息与其他系统数据，也不能把数据发往任何地方。首次打开页面时会先列出需要读取的数据项，经你同意后仅作只读访问；页面内容更新后须重新确认。

## 不在这里的东西

- **没有无感知的后台上传**：app 里没有统计或追踪 SDK；你的对话、记忆和健康汇总都存在你自己的服务器上。
- **自检输出不含密钥**：运行 `bash ~/openmousse/check.sh` 排查故障时，终端输出不包含任何令牌、密码与 API 密钥，可直接复制给他人协助排查。
