# 今天页与 04:00 日结
查看待处理、日程与报告，了解 03:45 日结与 04:00 会话重置的运作机制。

打开 OpenMousse app，在底栏第三格「今天」即可查看「今天页」；每天 03:45 的日结与 04:00 的会话重置由服务器在后台自动执行。

OpenMousse 的一天从 04:00 开始计算。今天页将当天需要你动手审批的事项、需要你到场的日程，以及各功能 Agent 送来的报告汇总在一处；凌晨则自动完成前一日的结论沉淀与对话归档。

## 今天页的构成

今天页自上而下分为三个常驻板块（早上 05:30–13:00 期间，日视图最上方还会单独展示一张起床卡，即起床报告）：

- **待处理**：需要你动手处理的事项。包括等你批准的确认卡、标签为「安全」的安全提醒（例如好友那边发来的话里夹着指令，或 Doorman 扣下的管家回复），以及快到期的待办和截止事项。
- **日程**：当天需要你到场的安排。
- **报告**：各功能 Agent 整理好送来供你阅读的信息。例如睡眠 Agent 生成的睡眠卡，记录昨晚睡了多久、恢复分，以及近 6 天的恢复分走势。

## 03:45 日结与 04:00 会话重置

系统按你的时区在每天凌晨执行以下两步操作：

1. **03:45 日结**：主对话与各功能 Agent 回顾过去一天的对话与数据，把当天的结论以及新得知的关于你的事实、偏好、决定与近况，分别写进各自的独立记忆与世界树。如果主对话发现某件事务被你反复交办，也会在日结后提议新建一个功能 Agent，放进收件箱等你同意。
2. **04:00 会话重置**：当天的对话按天归档。聊天记录按天翻阅，每一天的分界线均为 04:00。

> **提示：起床卡的显示时段**
> 起床卡（起床报告）仅在每天 05:30–13:00 出现在日视图最上方，不归入下方的「报告」板块中。

## 不在这里的东西

- **会议纪要卡不在「待处理」中**：多 Agent 短会结束后，会议纪要卡直接出现在「主对话」里（提供「确认」与「查看会议」操作），不会进入今天页的「待处理」。
- **Zen 里未存进库的想法不参与 03:45 日结**：你在 Zen 中随手记下的想法，或推敲时点击「只记下」的内容，仅保存为本地 Markdown 笔记，不会在 03:45 日结时自动写入世界树或任何 Agent 的记忆。
