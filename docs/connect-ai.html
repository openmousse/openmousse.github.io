指南

把你常用的 AI 接进世界树

将 Claude、ChatGPT、Gemini、Notion 与 Claude Code 接入世界树共用同一份长期记忆。

完成本指南后，你常用的外部 AI 应用将通过专属的 MCP 地址连接你的世界树：在每次对话开始前先读取你的背景与偏好，并在你说出关于自己的新事实、偏好、决定或近况时写回世界树。本指南假设你已部署 OpenMousse（或已单独安装 mousse-tree 服务）。

前提条件

  • •已运行 OpenMousse 服务器并完成 app 配对；或者已在拥有 Python 3.11 以上版本的服务器上单独安装了 mousse-tree 服务（见文末补充说明）。
  • •若要接入云端 AI 应用（Claude 网页版、ChatGPT、Gemini、Notion），你的世界树服务必须具备可访问的公网 HTTPS 地址（仅本机使用的命令行工具如 Claude Code 可使用局域网或 Tailscale 地址）。
  • •部分平台有订阅或版本要求：ChatGPT 需 Plus 及以上订阅；Notion 需 Business 及以上版本；Gemini 的连接器功能受服务商的可用地区限制，需在支持该功能的地区使用。

隐私说明

  • •写入与读取的内容：世界树接收的是你在这些 AI 应用中谈及的关于你的事实、偏好、决定与观点；各平台原有的对话记录仍留在原处。
  • •数据隔离边界：授权接入的外部 AI 应用仅能读写世界树，无法读取 OpenMousse 内的对话记录、健康数据及各功能 Agent 的独立记忆。
  • •来源识别与随时撤销：每个平台使用一条带专属令牌的独立地址，服务端凭令牌识别每片叶子的写入来源。你可以在 OpenMousse app 内随时删除任意平台的地址；删除后，世界树服务重启即断开该平台的连接（若世界树以系统服务运行，app 会自动重启它；否则需手动重启服务）。

步骤

1. 在 app 中获取专属接入地址

  1. 1.在 OpenMousse app 中打开「设置 → 世界树 → 连接你的 AI」。
  2. 2.选择你要接入的目标平台，生成并复制该平台带专属令牌的独立地址。
!
注意：公网 HTTPS 与管理页隔离

Claude（网页版）、ChatGPT、Gemini 与 Notion 均从各自的云端发起连接，因此你的世界树服务必须配置公网 HTTPS。若你使用反向代理对外开放单独安装的 mousse-tree，建议仅对外开放 /t 与 /m 两个路径前缀；请勿将管理页开放至公网。

2. 在目标平台配置 MCP 连接

按你所使用的平台，完成对应的连接配置：

平台配置路径与操作步骤
Claude1. 在 claude.ai 打开「设置 → 连接器（Connectors）→ 添加自定义连接器」。2. 名称填写「世界树」，粘贴 app 中对应的专属地址，认证方式留空。
ChatGPT1. 在 ChatGPT（需 Plus 及以上订阅）打开「设置 → Apps & Connectors → 高级」，开启 Developer mode。2. 点击「创建」，粘贴 app 中对应的专属地址，认证方式选择 None。
Gemini在 gemini.google.com 打开「设置 → Connected Apps → 添加自定义 app」，粘贴 app 中对应的专属地址（需在服务商支持该功能的地区使用）。
Notion1. 在 Notion（需 Business 及以上版本）打开「Custom Agent → Tools & Access → Custom MCP server」。2. 填入服务地址，认证方式选择 Bearer token，并将 app 给出的令牌填入对应栏位。
Claude Code在终端运行以下命令，将 <地址> 替换为 app 中给出的专属地址：claude mcp add --transport http tree <地址>
其他支持 MCP 的 AI在目标应用的 MCP、连接器或工具设置中，添加远程 MCP 服务（Streamable HTTP），粘贴 app 中对应的专属地址，无需配置认证。若其网页版暂不支持远程 MCP，可使用其命令行工具或任意支持 MCP 的客户端。

3. 粘贴自定义指令并关闭自带记忆

将以下指令复制到已接入应用的自定义指令中（Notion 写入该 Custom Agent 的 Instructions 中；Claude Code 写入项目的 CLAUDE.md 或全局 CLAUDE.md 中）：

文本
对话开始先调 profile 和 recall 了解我；我说出关于自己的新事实、偏好、决定、近况时调 remember。

随后，在该应用的设置中关闭其自带的记忆功能，避免两边记录不一致。

附：如果你只想单独安装世界树

如果你不需要部署完整的 OpenMousse，可以在拥有 Python 3.11 以上版本的服务器上单独运行世界树服务：

终端
pipx install "git+https://github.com/openmousse/openmousse#subdirectory=tree"mousse-tree init --name 你的称呼 --tz UTCmousse-tree install-service
  • •第一行也可替换为 pip install --user "git+https://github.com/openmousse/openmousse#subdirectory=tree"。
  • •将 --tz 参数替换为你的实际时区。
  • •服务默认仅监听本机 127.0.0.1:8787。运行 mousse-tree urls 可在终端查看各平台的含令牌地址（请仅在自己的终端内查看）。

成功的标志

当以下各项均成立时，说明接入已生效：

下一步

  • •世界树：了解叶子的存储格式、SQLite 与 Markdown 笔记库的切换方式（mousse-tree migrate）。
  • •数据与安全：查看外部应用的隔离机制与服务器数据存储位置。

Guides

Connect Your AIs to the Memory Tree

Connect Claude, ChatGPT, Gemini, Notion, and Claude Code to share the same long-term memory tree.

After completing this guide, your external AI apps will connect to your memory tree through dedicated MCP URLs: at the start of every conversation they read your background and preferences, and whenever you mention a new fact, preference, decision, or update about yourself they write it back to the memory tree. This guide assumes you have already deployed OpenMousse (or installed the standalone mousse-tree service).

Prerequisites

  • •A running OpenMousse server paired with the app, or a standalone mousse-tree service installed on a server with Python 3.11 or later (see the appendix at the end of this page).
  • •To connect cloud AI apps (Claude on the web, ChatGPT, Gemini, Notion), your memory tree service must be reachable at a public HTTPS URL (local command-line tools such as Claude Code can use a LAN or Tailscale address).
  • •Plan or region requirements on some platforms: ChatGPT requires a Plus subscription or higher; Notion requires a Business plan or higher; Gemini's connector feature is subject to Google's regional availability and must be used in a supported region.

Privacy Notes

  • •What is read and written: The memory tree receives facts, preferences, decisions, and opinions about you that come up in those AI apps; the full conversation transcripts in each platform stay where they are.
  • •Data isolation boundary: Authorized external AI apps can only read and write the memory tree; they cannot read OpenMousse conversation history, health data, or the independent memories of your functional agents.
  • •Source tracking and instant revocation: Each platform uses its own URL with a dedicated token, which the server uses to record the source of every leaf. You can delete any platform's URL in the OpenMousse app at any time; once deleted, restarting the memory tree service disconnects that platform immediately (if the memory tree runs as a system service, the app restarts it automatically; otherwise restart the service manually).

Steps

1. Get Dedicated Connection URLs in the App

  1. 1.In the OpenMousse app, open Settings → Memory tree → Connect your AI.
  2. 2.Select the target platform you want to connect, then generate and copy that platform's dedicated tokenized URL.
!
Important: Public HTTPS and Admin Page Isolation

Claude (web), ChatGPT, Gemini, and Notion connect from their own cloud servers, so your memory tree service must be served over public HTTPS. If you expose a standalone mousse-tree instance through a reverse proxy, expose only the /t and /m path prefixes; never expose the admin page to the public internet.

2. Configure the MCP Connection on Each Platform

Follow the steps for the platform you are connecting:

PlatformConfiguration Path and Steps
Claude1. On claude.ai, open Settings → Connectors → Add custom connector.2. Set the name to Memory tree, paste the dedicated URL from the app, and leave authentication blank.
ChatGPT1. In ChatGPT (Plus or higher required), open Settings → Apps & Connectors → Advanced and enable Developer mode.2. Click Create, paste the dedicated URL from the app, and set authentication to None.
GeminiOn gemini.google.com, open Settings → Connected Apps → Add custom app and paste the dedicated URL from the app (must be used in a region where the provider supports this feature).
Notion1. In Notion (Business or higher required), open Custom Agent → Tools & Access → Custom MCP server.2. Enter the server URL, select Bearer token authentication, and paste the token provided by the app into the token field.
Claude CodeRun the following command in your terminal, replacing <URL> with the dedicated URL from the app:claude mcp add --transport http tree <URL>
Other MCP-compatible AIsIn the target app's MCP, Connector, or Tools settings, add a remote MCP server (Streamable HTTP), paste the dedicated URL from the app, and leave authentication unconfigured. If its web app does not yet support remote MCP, use its CLI or any MCP-compatible client.

3. Paste Custom Instructions and Turn Off Built-In Memory

Copy the following instruction into the custom instructions of each connected app (for Notion, put it in the Custom Agent's Instructions; for Claude Code, put it in your project CLAUDE.md or global CLAUDE.md):

Text
At the start of a conversation, call profile and recall to learn about me; whenever I state a new fact, preference, decision, or update about myself, call remember.

Then turn off the app's built-in memory feature in its settings so the two systems do not drift out of sync.

Appendix: Install Only the Standalone Memory Tree

If you do not need a full OpenMousse deployment, you can run the memory tree service on its own on any server with Python 3.11 or later:

Terminal
pipx install "git+https://github.com/openmousse/openmousse#subdirectory=tree"mousse-tree init --name YourName --tz UTCmousse-tree install-service
  • •You can replace the first line with pip install --user "git+https://github.com/openmousse/openmousse#subdirectory=tree".
  • •Replace the --tz value with your actual time zone.
  • •By default, the service listens only on 127.0.0.1:8787. Run mousse-tree urls to view the tokenized URLs for each platform in your terminal (view these only inside your own terminal).
