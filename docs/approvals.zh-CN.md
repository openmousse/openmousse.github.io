# 先问你（收件箱）
付款、对外发送、提交与登录等撤不回的操作先生成确认卡并锁定参数，等你批准后再执行。

在 OpenMousse app 的「今天 → 待处理」、对应对话消息的下方，或手机系统通知中均可查看并处理确认卡。

为了防止 Agent 在未经你同意的情况下对外发信、付款或改动关键数据，OpenMousse 对所有工具调用实行分级管控。凡属撤不回的操作，Agent 一律先停下来生成一张锁定参数的确认卡，交由你批准后才执行。

## 工具调用三档机制

系统内核将 Agent 的工具调用分为三档 [即将推出]：

1. **只读操作**：查询世界树、读取日程或查看看板等不改动数据的操作，由 Agent 直接执行。
2. **撤得回的操作**：在内部新增或修改记录等可逆操作，由 Agent 直接执行，并在该条回复下方附带一个改动编号；你只需回复「撤销」，系统即可将该次改动恢复原状。
3. **撤不回的操作**：付款、对外发送、提交表单、账号登录等操作，一律停下来生成确认卡，锁定调用参数；经你点击批准后，系统严格照原参数执行一次。

## 确认卡的来源与处理流程

除第三档工具调用外，以下场景也会在收件箱与「今天 → 待处理」中生成确认卡或提醒：

- **代办 Agent 的外部操作**：代办 Agent 在隔离沙箱中比价、填表后，涉及提交、发送、登录或付款时生成确认卡。
- **管家的对外承诺与 Doorman 复查**：好友或好友的管家找你约时间、要东西时，管家不会自行答应，而是生成确认卡交给你定；管家发出的每一句回复若被 Doorman 判定不妥，也会扣下并交由你决定照发、修改或不发。
- **赛博的数据修改与世界树写入** [即将推出]：赛博通过其装载的功能 Agent 请求修改数据，或请求将内容写入世界树时，均会生成确认卡等你确认。
- **新建或提议功能 Agent**：每晚日结后，主对话提议将你反复做的事建为新 Agent 时，会放进收件箱等你同意。
- **外来指令安全提醒**：当好友那边发来的消息里夹着试图操纵系统的指令时，系统会在「今天 → 待处理」中生成标签为「安全」的提醒。

你在任意一处（今天页待处理、对话消息下方或通知）批准或拒绝后，该确认卡即处理完毕，并在原处收起为一行回执。

## 不在这里的东西

- **会议纪要不在收件箱中审批**：多 Agent 短会的纪要卡直接出现在主对话中，经你在主对话内点击确认后写入日程与各 Agent 看板。
- **世界树的「待确认」叶子不在收件箱中**：开启世界树的「待确认」开关后，系统拿不准的记忆会停在「设置 → 世界树」（或记忆页年轮环外）的「待确认」列表中，不混入收件箱的确认卡。
