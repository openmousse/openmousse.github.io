# 建立并管理功能 Agent
在主对话中通过方案卡或在 app 内新建功能 Agent，并为它配置职责与模型。

完成本指南后，你将建立一个新的功能 Agent（例如专门整理行业报告的研究 Agent），为它设定职责与所用模型，并了解如何通过直接对话、主对话转交或召集会议与它协作。本指南假设你已部署 OpenMousse 并完成客户端配对。

## 前提条件

- 已运行 OpenMousse 服务器并配对手机或网页客户端。
- 服务器已配置至少一个可用的模型服务（或已接入 OpenClaw / Hermes）。

## 隐私说明

- **记忆与数据隔离**：每个功能 Agent 拥有独立的对话记录、独立记忆与专属看板，与其他功能 Agent 分开存放。
- **共享世界树**：各功能 Agent 在回答前均可查询世界树，并在得知关于你的新事实、偏好、决定或结论时写入世界树（每天 03:45 日结时也会汇总写入）。
- **外部应用不可见**：你手动授权接入世界树的外部 AI 应用（如 Claude、ChatGPT）无法读取任何功能 Agent 的独立记忆、对话记录与看板数据。

## 步骤

### 1. 选择一种方式建立功能 Agent

代办和「学习与办公」两个 Agent 默认启用；针对健身、饮食、睡眠等其余日常领域，你可以按以下任意一种方式按需建立对应的功能 Agent（从一句话描述到试聊满意再创建的引导式新建流程 [即将推出]）：

| 建立方式 | 操作步骤 |
| --- | --- |
| **方式 A：在主对话中通过方案卡建立** | 1. 打开对话列表第一行的「主对话」。<br>2. 说明你希望新 Agent 负责的事务，例如：「帮我建一个研究 Agent，专门整理行业报告和纪要。」<br>3. 主对话会生成一张包含名称与职责设定的**方案卡**；核对无误后点击确认，系统即建立该 Agent。 |
| **方式 B：在 app 内手动填写建立** | 1. 在 app 的「对话」页顶部点金色 **+** 按钮（「新建」）→「新建 Agent」（若还不确定，也可在该页面选择「尚未确定？先讨论方案」）。<br>2. 依次填写该 Agent 的**名称**、**职责说明**并选择它所使用的**模型**，保存后即完成创建。 |
| **方式 C：批准日结后的收件箱提议** | 每晚 03:45 日结后，若主对话发现某类事务被你反复处理，会自动提议将其独立为一个新的功能 Agent，并生成确认卡放入收件箱与今天页的「待处理」；你点击同意后即建立该 Agent。 |

### 2. 与功能 Agent 日常协作

建立完成后，你可以通过三种路径使用该功能 Agent：

1. **直接进入独立对话**：在对话列表中点开该功能 Agent，直接向它交代任务或查阅它的独立记忆。
2. **由主对话转交**：在主对话中直接说出需求，主对话会识别事务类型并转交给对应的功能 Agent 处理。
3. **召集多个 Agent 开短会**：当一项决定涉及多个领域（例如出差期间如何同时调整研究进度、睡眠与饮食），你可以在主对话中提出（或在 app 内直接发起会议）。主对话会召集相关功能 Agent 轮流发言（每轮每个 Agent 最多发言一次，可互相 `@`），讨论结束后在主对话中生成一张**会议纪要卡**，列出决定与每条待办的负责 Agent 及时间。

> **注意：会议纪要须经你确认才写入数据**
> 会议过程中各 Agent 仅作讨论，不会修改任何日程或看板数据。会议纪要卡出现在主对话中（不在今天页的「待处理」里）；只有当你点击确认后，纪要中的待办事项才会正式写入你的日程以及对应功能 Agent 的看板。你也可以补充意见并开启下一轮讨论。

### 3. 切换看板视图管理结构化数据

每个功能 Agent 均配有专属看板，用于维护它所负责领域的结构化记录（如文献台账、训练计划或待办事项）。进入该 Agent 的看板后，你可以按需要在五种视图之间切换：**表格**、**看板**、**日历**、**时间线**与**图表**。

## 成功的标志

当以下各项均成立时，说明新的功能 Agent 已投入工作：

- [ ] 新建的功能 Agent 已出现在你的对话列表中，且拥有独立的对话页与看板。
- [ ] 在主对话中提出属于该 Agent 职责范围的需求时，主对话能够正确转交给它，或将它召入短会参与讨论。
- [ ] 在主对话中点击确认会议纪要卡后，分配给该 Agent 的待办已写入它的看板中，并可在表格、看板、日历、时间线、图表五种视图间切换查看。

## 下一步

- **Agents**：全面了解主对话、功能 Agent、群聊、赛博与管家的权限边界。
- **先问你（收件箱）**：了解功能 Agent 执行操作时的三档权限与确认卡机制。
- **今天页与 04:00 日结**：了解各功能 Agent 如何向今天页投递报告并在凌晨完成日结。
