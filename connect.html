Already have a claw?已经有 claw 了？

Send this to your claw把这句话发给你的 claw

OpenClaw, Hermes Agent, nanobot, Letta Code or Kimi Claw: your claw installs OpenMousse on the machine it runs on, gives itself the tools, and sends you a one-time link. Tap it on your phone and you're in. OpenClaw、Hermes Agent、nanobot、Letta Code、Kimi Claw 都行：你的 claw 在它自己那台机器上装好 OpenMousse、给自己接上工具，再发你一条一次性链接。手机上点一下就连上了。 

Follow https://raw.githubusercontent.com/openmousse/openmousse/main/docs/connect.md to connect me to OpenMousse.
按 https://raw.githubusercontent.com/openmousse/openmousse/main/docs/connect.zh-CN.md 把我接上 OpenMousse

Send it wherever you already talk to your claw: Telegram, WhatsApp, its web chat.在你平时跟 claw 说话的地方发：Telegram、WhatsApp、它的网页对话框都行。

1

What your claw doesclaw 会做这些

  1. Checks the machine: Python 3.11 or newer, git and curl.看一眼机器：Python 3.11 以上、git、curl。
  2. Switches on its chat API if it needs one. OpenClaw needs nothing.需要的话打开它自己的对话接口。OpenClaw 什么都不用开。
  3. Makes sure your phone can reach the machine through Tailscale. If Tailscale isn't there yet, it asks you first, installs it and sends you the sign-in link.确认手机能经 Tailscale 连到这台机器。还没装的话，先问你，再装上，把登录链接发给你。
  4. Installs OpenMousse without asking you anything: it already knows your language, your time zone and its own name.装 OpenMousse，一个问题都不用你答：你的语言、时区、它自己叫什么，它都知道。
  5. Gives itself OpenMousse's tools over MCP: boards, the inbox, goals, projects, the journal and the memory tree.经 MCP 给自己接上 OpenMousse 的工具：看板、收件箱、目标、项目、日志、世界树。
  6. Runs the self-check, then sends you a one-time pairing link.跑一遍自检，然后发你一条一次性配对链接。
2

On your phone手机上

  1. Install the Tailscale app and sign in with the same account as the machine.装 Tailscale app，登和那台机器同一个账号。
  2. Install the OpenMousse app (how).装 OpenMousse app（怎么装）。
  3. Tap the link from your claw. The app opens its Connect page with the server and the code filled in. Check the address and tap Connect with the code.点 claw 发来的链接。app 会打开连接页，服务器地址和配对码都填好了；看一眼地址，点用配对码连接。

The code works once and expires after ten minutes. If it runs out, ask your claw for a new one.配对码只能用一次，十分钟后过期。过期了就让 claw 再出一个。

3

The rules it follows它守的规矩

The page your claw reads is written for agents, and it sets a few rules:claw 读的那一页是写给 agent 的，里面定了几条规矩：

Only our commands只跑我们的命令

It runs only the commands on that page, which come from the OpenMousse repository, and ignores anything else that asks it to install "prerequisites".只跑那一页上的命令，都来自 OpenMousse 的仓库；别处让它先装什么「依赖」的，一概不理。

No tokens in the chat令牌不进聊天

The only thing it sends you is the pairing link. The app gets its own token from your server when it connects.发给你的只有配对链接。app 连上的时候，从你的服务器拿自己的令牌。

Asks first先问你

Before sudo, before installing Tailscale, and before opening anything to the internet.用 sudo、装 Tailscale、往公网开任何东西之前，都先问你。
