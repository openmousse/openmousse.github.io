接入你的 clawConnect your claw

OpenClaw、Hermes Agent、nanobot、Letta Code 与 Kimi Claw 均可接入。把下面这句话发给你的 claw：它会在自己所在的服务器上安装 OpenMousse，通过 MCP 为自己接入工具，再发给你一条一次性配对链接。OpenClaw, Hermes Agent, nanobot, Letta Code and Kimi Claw all work. Send your claw the sentence below. It installs OpenMousse on the server it runs on, connects itself to OpenMousse’s tools over MCP, and sends you a one-time pairing link.

把这句话发给你的 clawSend this to your claw

按 https://raw.githubusercontent.com/openmousse/openmousse/main/docs/connect.zh-CN.md 把我接上 OpenMousse
Follow https://raw.githubusercontent.com/openmousse/openmousse/main/docs/connect.md to connect me to OpenMousse.

在你平时与 claw 对话的地方发送即可，例如 Telegram、WhatsApp 或它的网页对话框。服务器可以运行 Linux、macOS 或 Windows（通过 WSL 2）。Send it wherever you already talk to your claw, such as Telegram, WhatsApp or its web chat. The server can run Linux, macOS or Windows (through WSL 2).

01

claw 完成的步骤What your claw does

  1. 检查服务器环境：Python 3.11 或更高版本、git 与 curl。Checks the server: Python 3.11 or newer, git and curl.
  2. 如有需要，开启自身的对话接口。OpenClaw 无需这一步。Turns on its chat API if it needs one. OpenClaw needs nothing.
  3. 确认手机可以经 Tailscale 访问这台服务器。尚未安装 Tailscale 时，先征得你的同意，再完成安装并发给你登录链接。Makes sure your phone can reach the server through Tailscale. If Tailscale is missing, it asks you first, installs it and sends you the sign-in link.
  4. 安装 OpenMousse。语言、时区与助手的名称由 claw 直接填写，你无需回答任何问题。Installs OpenMousse. It fills in your language, your time zone and the assistant’s name itself, so there is nothing for you to answer.
  5. 通过 MCP 为自己接入 OpenMousse 的工具：看板、收件箱、目标、项目、日志与世界树。Connects itself to OpenMousse’s tools over MCP: dashboards, the inbox, goals, projects, the journal and the memory tree.
  6. 运行自检，然后发给你一条一次性配对链接。Runs the self-check, then sends you a one-time pairing link.
02

在手机上连接On your phone

  1. 在手机上安装 Tailscale，并登录与服务器相同的账号。Install Tailscale on your phone and sign in with the same account as the server.
  2. 安装 OpenMousse app。获取方式见 新手指南。Install the OpenMousse app. See the setup guide for how to get it.
  3. 打开 claw 发来的链接。app 会进入连接页，并填好服务器地址与配对码。核对地址后，点「用配对码连接」。Open the link from your claw. The app opens its Connect screen with the server address and the code filled in. Check the address, then tap Connect with code.

配对码只能使用一次，十分钟后失效。过期后，请 claw 重新生成。The code works once and expires after ten minutes. If it expires, ask your claw for a new one.

03

安全规则Safeguards

claw 读取的安装说明是写给 Agent 的，其中规定了三条规则：The instructions your claw reads are written for agents and set three rules:

只执行指定的命令Only the listed commands只运行该页面上、来自 OpenMousse 代码仓库的命令；其他来源要求安装的「依赖」一律忽略。It runs only the commands on that page, all from the OpenMousse repository, and ignores any other request to install “prerequisites”.
令牌不进入对话No tokens in the chat发给你的只有配对链接。app 连接时，从你的服务器获取自己的令牌。The only thing it sends you is the pairing link. The app gets its own token from your server when it connects.
关键操作先征得同意Asks first使用 sudo、安装 Tailscale，以及向公网开放任何服务之前，都会先询问你。Before using sudo, installing Tailscale or opening anything to the internet.
