Turn your OpenClaw into a personal assistant on your phone.把你的 OpenClaw，变成手机上的私人助理。

Like Meta's Muse: chat with it from your phone, give each part of your life its own Agent, and let them come to you. The difference is that the agent runs on your own machine, with your own model account, and the memory is yours. 像 Meta 的 Muse 一样：在手机上跟它对话，生活的每一块交给一个 Agent，它们会主动来找你。不同的是，agent 跑在你自己的机器上，用你自己的模型账号，记忆也是你自己的。

What OpenMousse isOpenMousse 是什么

It doesn't bring an agent of its own: your OpenClaw already is one. OpenMousse adds three things around it.它不自带 agent：你的 OpenClaw 本身就是。OpenMousse 在它周围加了三样东西。

app/

An iPhone app一个 iPhone app

Chat with your claw by text, voice, photos or files, and get a notification when it answers. Each Agent has its own page with a chat and a dashboard, and the Today page gathers what they suggest. There's a web version too, served by your own server.跟你的 claw 对话，文字、语音、照片、文件都行，回完推送给你。每个 Agent 有自己的页面，对话和看板在一起；「今天」页汇总它们给你的建议。也有网页版，由你自己的服务器提供。

server/

A small server next to OpenClawOpenClaw 旁边的一个小服务

Handles the app's sign-in, relays chats and sends notifications. Ask for a new Agent in chat and it sets one up in OpenClaw. Every night it writes a digest for each Agent, so each one remembers yesterday.负责 app 的登录、对话转发和推送。你在对话里说要一个新 Agent，它就去 OpenClaw 里建好。每天夜里给每个 Agent 做一次日结，让它们记得昨天。

tree/

The memory tree世界树

An MCP server holding one memory about you. Claude.ai, ChatGPT, Gemini, Notion and your claw all connect to it, so what one learns, the others know. It works without OpenClaw too.一个 MCP 服务，存着一份关于你的记忆。Claude.ai、ChatGPT、Gemini、Notion 和你的 claw 都接在这棵树上，一个平台知道了，其他平台也知道。没有 OpenClaw 也能单独用。

Install安装

You need a Linux machine running OpenClaw with a model set up, and an iPhone. Then one command:需要一台装好 OpenClaw 并配好模型的 Linux 机器，和一部 iPhone。然后一条命令：

curl -fsSL https://openmousse.ai/install | bash

It asks four questions (language, where OpenClaw lives, time zone, what to call the assistant), sets up the server, the memory tree and the daily digest, and prints how to connect your phone. Running it again only fills in what's missing.它会问四个问题（语言、OpenClaw 在哪、时区、助手叫什么），装好服务端、世界树和日结，最后告诉你手机怎么连。再跑一遍只补缺的。

Why OpenMousse为什么做 OpenMousse

When Meta's Muse was everywhere, the author wrote a post about it: Muse is a claw in an app shell, and the trouble is that it's centralized. You can't pick the model, the memory starts from zero, and your data can't leave. OpenMousse is the answer to that post.Muse 刷屏的那几天，作者写了一篇文章：Muse 其实是一只套着 app 外壳的 claw，问题在于太中心化，模型选不了，记忆从零开始，数据也带不走。OpenMousse 就是那篇文章的回答。
