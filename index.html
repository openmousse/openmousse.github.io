A personal agent that lives on your own machine.住在你自己机器上的私人 agent。

OpenMousse is the app for your OpenClaw: chat with it from your phone, give each part of your life its own Agent, and keep one memory that Claude, ChatGPT and Gemini all share. OpenMousse 是你的 OpenClaw 的 app：在手机上直接跟它对话，生活的每一块交给一个 Agent，再用一份记忆把 Claude、ChatGPT、Gemini 串起来。

What you get你能得到什么

OpenMousse doesn't bring an agent of its own. It gives the OpenClaw you already run an app, Agents with their own dashboards, and a memory every AI can share.OpenMousse 不自带 agent。它给你已经在跑的 OpenClaw 一个 app、各自带看板的 Agents，和一份所有 AI 都能共用的记忆。

Your agent in your pocket口袋里的 agent

Streaming chat, voice notes, photos and files, push notifications. Same skills, same chat channels, same model accounts as your OpenClaw.流式对话、语音输入、照片和文件、推送通知。skills、聊天渠道、模型账号都和你的 OpenClaw 是同一套。

An Agent for each part of your life生活的每一块，一个 Agent

Fitness, meals, sleep, job applications… Each is a real OpenClaw agent with its own memory, skills and dashboard. Ask for one in chat and it gets built.健身、饮食、睡眠、求职……每个都是真正的 OpenClaw agent，有自己的记忆、skills 和看板。在对话里说一句就建好。

It comes to you它会主动找你

A morning report, suggestion cards that refresh when new data arrives (a workout finished, a meal logged), and a daily digest so every Agent remembers yesterday.起床报告；新数据一到（练完、记了一餐）就更新的建议卡；每天的日结，让每个 Agent 记得昨天。

One memory for every AI所有 AI 共用一份记忆

The memory tree is an MCP server that Claude.ai, ChatGPT, Gemini and Notion connect to. What one of them learns about you, the others know. It also works without OpenClaw.世界树是一个 MCP 服务，Claude.ai、ChatGPT、Gemini、Notion 都能接。一个平台知道了关于你的事，其他平台也知道。没有 OpenClaw 也能单独用。

Your data stays with you数据留在你这里

On your server存在你的服务器上

  • Conversations, Agents and their memory对话、Agents 和它们的记忆
  • Apple Health daily summaries (only if you allow it)Apple 健康的每日汇总（你允许才会同步）
  • Files and voice notes you send你发的文件和语音

  • Voice notes to your transcription service (OpenAI by default, or your own Whisper)语音发给你配置的转写服务（默认 OpenAI，也可以用自己的 Whisper）

Install安装

You need a Linux machine running OpenClaw with a model set up. Then one command:需要一台装好 OpenClaw 并配好模型的 Linux 机器。然后一条命令：

curl -fsSL https://openmousse.ai/install | bash

It asks four questions (language, where OpenClaw lives, time zone, what to call the assistant), sets up the server, the memory tree and the daily digest, and prints how to connect your phone. Running it again only fills in what's missing.它会问四个问题（语言、OpenClaw 在哪、时区、助手叫什么），装好服务端、世界树和日结，最后告诉你手机怎么连。再跑一遍只补缺的。
