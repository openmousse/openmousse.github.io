Muse？Claws！Muse?Claws!

Muse 是披着 app 外壳的 claw。OpenMousse 也给你这层壳，但里面住的是你自己的 claw：用你挑的模型，读你自己的记忆，做你要的功能。

Muse is a claw in an app shell. OpenMousse gives you the same shell, but the claw inside is your own: the model you pick, your own memory, the features you want.

需要：一台跑着 claw（比如 OpenClaw）的机器，加上随便哪一家的模型订阅。

You need a machine running a claw (such as OpenClaw), plus a model plan from any provider.

观察Observation

每换一个平台，就得重新自我介绍一次Every new platform, another self-introduction

你是不是也这样：根据需求换着用不同的 AI，每家都存了一份关于你的记忆，互相却不通。

Sound familiar? You switch between AIs for different jobs, and each one keeps its own memory of you, but they never talk to each other.

早上跟 ChatGPT 说早餐换成燕麦了，晚上问 Claude 明天吃什么，它一无所知。

In the morning you tell ChatGPT you've switched to oats for breakfast. In the evening you ask Claude what to eat tomorrow, and it has no idea.

Muse 把这件事做到了头：模型是它家的，记忆从零开始，数据进了它的云就带不走。拆开看，它就是一只 claw 套着 app 的壳，接了一堆 MCP，读着你早就存好的数据。问题在于太中心化。

Muse takes this to the extreme: the model is Meta's, the memory starts from zero, and once your data is in their cloud it can't leave. Take it apart and it's a claw in an app shell, plugged into a pile of MCPs and reading data you'd already handed over. The problem is that it's centralized.

Android or iPhone, neither forces you to use only its own apps, and apps built by countless creators make up your day. The next device should do at least as well:

记忆Memory

模型可以换，功能可以换，但记忆只有一棵树Models can change, features can change, but there's only one memory tree

所以第一步先解决记忆。世界树是跑在你自己服务器上的一个 MCP 服务：树干是从 ChatGPT、Claude、Gemini 的导出里提炼出来的你；Claude.ai、ChatGPT、Gemini、Notion 和你的 claw 都是树上的枝，开口前先读树，学到关于你的新事实就写回去，每条都带来源和日期。

So memory comes first. The memory tree is an MCP server on your own machine. Its trunk is you, distilled from your ChatGPT, Claude and Gemini exports. Claude.ai, ChatGPT, Gemini, Notion and your claw are its branches: they read the tree before answering and write back new facts about you, each stamped with its source and date.

记忆在你手里Your memory stays with you一个 SQLite 文件，想搬就搬，想删就删。One SQLite file: move it or delete it whenever you like.
树不花钱The tree costs nothing它只存、只搜，不调用模型。It only stores and searches. It never calls a model.
接法很土Low-tech setup每个平台一个专属地址，当自定义连接器加上，再加一句「对话开始先读我的档案」。Each platform gets its own URL, added as a custom connector, plus one line: “read my profile at the start of every chat.”

创作者Creators

你的需求，也会有人需要What you need, someone else needs too

每个人的需求不一样，但你的需求，这世界上总有人也有。手机因为有了做 app 的人才变得好用，agent 也一样：缺的是创作者，不是新的账单。

Everyone's needs are different, but whatever you need, someone out there needs it too. Phones got good because people built apps for them, and agents are the same: what's missing is creators, not another bill.

判断Verdict

Muse 和自己搭，差在哪Muse vs. building your own

除了 Meta 自带的用户基数，Muse 在技术上没有护城河：每家模型厂商都能很快做出同样的东西，就像当年手机厂商互相竞争。

Apart from Meta's user base, Muse has no technical moat: any model company could ship the same thing fast, just like the phone makers' race years ago.

OpenClaw 给 agent 指了一个方向，也长出了一个巨大的开源社区。为什么不再开一个 OpenMousse 社区，一起给个人 agent 做点贡献？

OpenClaw pointed the way for agents and grew a huge open-source community. Why not start an OpenMousse community and build personal agents together?

需要一台跑着 claw（比如 OpenClaw）、配好模型的 Linux 机器。然后一条命令：

You need a Linux machine running a claw (such as OpenClaw) with a model set up. Then one command:

curl -fsSL https://openmousse.ai/install | bash

它会问四个问题（语言、OpenClaw 在哪、时区、助手叫什么），装好服务端、世界树和日结，最后告诉你手机怎么连。再跑一遍只补缺的。

It asks four questions (language, where OpenClaw lives, time zone, what to call the assistant), sets up the server, the memory tree and the daily digest, and tells you how to connect your phone. Running it again only fills in what's missing.
