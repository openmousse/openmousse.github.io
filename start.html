在自己的服务器上安装 OpenMousseSet up OpenMousse on your own server

从准备服务器到在手机上完成第一次对话，共六步，按顺序完成即可。OpenMousse 没有预设的 Agent：你提出需要，它为你创建。Six steps, from preparing a server to your first conversation on your phone. Work through them in order. OpenMousse has no preset agents: tell it what you need and it builds them.

已有 clawAlready have a claw?第 2 至 4 步可以交给它完成：发送一句话即可。It can do steps 2 to 4 for you. Send it one sentence. 不想自己部署Rather not run a server?申请托管服务器：我们为你准备一台专属的云服务器，免费试用 30 天。Apply for a hosted server: we set up a dedicated cloud server for you, free for 30 days.

01

准备What you need

  • 一台长期开机的服务器A server that stays on

    Linux、macOS 或 Windows 均可，例如家中的一台电脑、Mac mini 或云服务器。需要 git 与 Python 3.11 或更高版本。Linux, macOS or Windows: a computer at home, a Mac mini or a cloud server. It needs git and Python 3.11 or newer.

    Linux推荐 Ubuntu 或 Debian，需带 systemd。Ubuntu or Debian is easiest; it needs systemd.
    macOS用 Homebrew 安装：brew install git python。在「系统设置」中关闭自动睡眠，让 Mac 保持在线。Install with Homebrew: brew install git python. Turn off automatic sleep in System Settings so the Mac stays online.
    Windows在 PowerShell 中运行 wsl --install，安装 WSL 2 与 Ubuntu。之后的命令都在 Ubuntu 终端中运行。Run wsl --install in PowerShell to set up WSL 2 with Ubuntu. Run every later command in the Ubuntu terminal.
  • 一个 clawA claw

    claw 是运行在服务器上的开源 AI Agent 程序。OpenClaw 功能最完整：完成 openclaw onboard，Gateway 正在运行，并用你自己的账号配置好模型（Claude 或 ChatGPT 的订阅，或 API 密钥）。openclaw.ai ↗A claw is an open-source AI agent that runs on your server. OpenClaw is the most complete: openclaw onboard done, the Gateway running, and a model set up on your own account (a Claude or ChatGPT subscription, or an API key). openclaw.ai ↗

    Hermes Agent、nanobot、Letta Code，或任何提供 OpenAI 兼容对话接口的 Agent 也可以使用，需先开启其接口。后台任务、执行审批与定时任务需要 OpenClaw。Hermes Agent, nanobot, Letta Code or any agent with an OpenAI-compatible chat API also work, once that API is on. Background tasks, approvals and scheduled jobs require OpenClaw.

  • 一部手机A phone

    iPhone 或 Android 手机。app 安装在手机上，Agent 的通知会送达这里。An iPhone or an Android phone. The app runs there, and your agents’ notifications arrive there.

  • 一个 Tailscale 账号A Tailscale account

    免费。手机在任何网络下都能访问你的服务器，服务器无需暴露在公网。tailscale.com ↗Free. Your phone reaches the server from any network, and the server stays off the public internet. tailscale.com ↗

02

安装服务Install the server

在服务器的终端中运行下面这条命令（Windows 在 Ubuntu 终端中运行）：Run this in a terminal on the server (on Windows, in the Ubuntu terminal):

curl -fsSL https://openmousse.ai/install | bash

安装程序会询问四项：语言；你的 claw（直接回车表示 OpenClaw，随后填写 openclaw.json 所在的文件夹，通常是 ~/.openclaw；也可以填写 hermes、nanobot、letta，或其他 Agent 的 OpenAI 兼容接口地址）；时区；助手的名称。随后，它会安装服务、世界树与每日归档，并为 OpenClaw 添加规则与 skill。修改 openclaw.json 之前会先备份，修改后自动校验，再重启 Gateway（无法重启时会提示你）。The installer asks four questions: your language; your claw (press Enter for OpenClaw, then give the folder that holds openclaw.json, usually ~/.openclaw; or answer hermes, nanobot, letta, or another agent’s OpenAI-compatible URL); your time zone; and the assistant’s name. It then sets up the server, the memory tree and the daily archive, and adds rules and skills to OpenClaw. It backs up openclaw.json before changing it, checks the result and restarts the Gateway (or tells you to).

另有两项可以直接回车跳过：服务器上已在同步的 Obsidian 库文件夹（世界树会写入其中，每条记忆一篇笔记）；以及是否通过 Tailscale Funnel 开放公网 HTTPS。开放后，其他 AI 可以连接世界树，分享可以生成链接，好友也可以添加你。尚未安装 Tailscale 时可以先跳过，在第 3 步重新运行安装命令时再开启。Two more you can skip with Enter: an Obsidian vault folder that already syncs to this server (the memory tree goes into it, one note per memory), and whether to open public HTTPS through Tailscale Funnel. With it, your other AIs can reach the memory tree, shares get links and friends can add you. No Tailscale yet? Skip it, and turn it on when you run the install command again in step 3.

安装结束时，程序会显示服务器地址与手机令牌。令牌只显示一次，请先保存，第 4 步会用到。When it finishes, the installer prints the server address and a phone token. The token is shown only once; save it for step 4.

03

从手机访问Reach it from your phone

服务器加入 Tailscale 之前，服务只在本机监听，手机无法访问。先在服务器上安装 Tailscale。Linux 与 WSL：Until the server joins Tailscale, the service listens only on the machine itself, so your phone can’t reach it. Install Tailscale on the server first. On Linux and WSL:

curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up

macOS：从 App Store 安装 Tailscale 并登录，或运行 brew install --cask tailscale。On macOS: install Tailscale from the App Store and sign in, or run brew install --cask tailscale.

  1. 在手机上安装 Tailscale，并登录同一个账号。Install Tailscale on your phone and sign in with the same account.
  2. 重新运行第 2 步的安装命令。服务会改为监听 Tailscale 地址，并显示 app 中要填写的地址，形如 http://100.x.y.z:8080。Run the install command from step 2 again. The server moves to its Tailscale address and prints what to enter in the app, such as http://100.x.y.z:8080.

如果第 2 步时服务器已经在 Tailscale 中，安装程序会直接使用这个地址，只需完成手机端。不使用 Tailscale 时，可以用 Caddy、nginx 或 tailscale serve 将 127.0.0.1:8080 反向代理为 HTTPS 地址，并在 app 中填写这个地址。If the server was already on Tailscale in step 2, the installer used that address straight away and only the phone is left. To go without Tailscale, put 127.0.0.1:8080 behind HTTPS with Caddy, nginx or tailscale serve, and enter that address in the app.

04

安装 app 并连接Install the app and connect

  1. 获取 app。app 通过邀请分发：发送邮件至 hello@openmousse.ai 申请，注明你使用 iPhone 还是 Android 手机；也可以在 GitHub Discussions 留言。开发者也可以自行构建仓库中的 app/（iOS 需要 Apple 开发者账号）。Get the app. It is available by invitation: email hello@openmousse.ai and say whether you use an iPhone or an Android phone, or leave a message in GitHub Discussions. Developers can also build app/ from the repository (iOS needs an Apple developer account).
  2. 打开 app，用邮箱登录（会收到一个 6 位验证码）。在连接页填写服务器地址（第 3 步）与接入令牌（第 2 步的手机令牌）。Open the app and sign in with your email (you receive a 6-digit code). On the Connect screen, enter the server address from step 3 and, as the access token, the phone token from step 2.
  3. 允许通知。Agent 发现需要你处理的事项时，会通过通知告诉你。Allow notifications. Your agents use them when something needs you.
05

导入你的数据Bring your data in

初始时，它对你一无所知。以下几项能帮助它更快了解你；每一项都可以跳过，之后再做。At first it knows nothing about you. Each of these helps it catch up; skip any of them and come back later.

从其他 AI 迁移记忆Move your memories from other AIs

在 ChatGPT、Claude 与 Gemini 中分别发送下面这段话，再把回答完整粘贴到主对话。它会整理进你的世界树，你可以在「我 → 世界树」中查看与删除。Send this to ChatGPT, Claude and Gemini, then paste each answer into the main chat. It files what it learns into your memory tree, where you can review and delete it under Me → Memory tree.

请逐条列出你记得的关于我的信息：我的背景、正在做的事、习惯与偏好，以及我做过的决定。只列事实，不作评价。
List everything you remember about me, one item per line: my background, what I’m working on, my habits and preferences, and decisions I’ve made. Facts only, no commentary.

让它向你提问Let it interview you

在主对话中说「问我几个问题，了解一下我」。它每次提出几个问题，并记下你的回答。In the main chat, say “Ask me a few questions to get to know me.” It asks a few at a time and remembers your answers.

健康数据Health data

连接后，app 会请求读取 Apple 健康（Android 为 Health Connect）的权限。授权后，首次同步会读取过去一年的睡眠、心率、步数与训练等数据，睡眠报告与恢复分数据此计算。不授权也可以正常使用，只是这些数据为空。Once connected, the app asks to read Apple Health (Health Connect on Android). Allow it and the first sync reads back a year of sleep, heart rate, steps, workouts and more; sleep reports and the recovery score come from here. Without it, everything else still works.

文件Files

PDF、Word、表格、演示文稿与照片，直接在对话中发送即可。PDFs, Word files, spreadsheets, slides and photos: send them in the chat and it reads them.

让其他 AI 共用这份记忆Let your other AIs share this memory

Claude、ChatGPT、Gemini、DeepSeek、通义千问与 Kimi 等支持 MCP 的 AI，都可以连接你的世界树。在 app 中打开「我 → 世界树 → 接入你的 AI」：每个 AI 有独立的地址与步骤；再把一句指令粘贴到它的自定义指令中。此后，它会在回答前读取世界树，并写回你提到的新信息。Claude, ChatGPT, Gemini, DeepSeek, Qwen, Kimi and any other AI that speaks MCP can connect to your memory tree. In the app, open Me → Memory tree → Connect your AI. Each AI gets its own address and steps; paste the one-line instruction into its custom instructions. From then on it reads the tree before answering and writes back what you tell it about yourself.

这些 AI 从各自的云端连接，因此世界树需要一个公网 HTTPS 地址：安装时选择开放，或按 app 中的提示开启。These apps connect from their own clouds, so the tree needs a public HTTPS address first: say yes when the installer asks, or follow the steps in the app.

之后每创建一个 Agent，它都会先说明这个 Agent 需要记录哪些数据、数据来自哪里。Later, each time you build an agent, it first tells you what data that agent will keep and where it comes from.

开始第一次对话Start your first conversation

OpenMousse 没有预设的 Agent。在主对话中说出你希望它负责的事，例如：OpenMousse has no preset agents. In the main chat, say what you want looked after, for example:

帮我改善睡眠我在准备 GRE 考试帮我记账跟进我的签证材料
Help me sleep betterI’m preparing for the GRETrack my spendingKeep track of my visa paperwork

它会先提几个问题，再给出方案：记录哪些数据、接入哪些渠道、看板展示什么，以及与其他 Agent 如何协作。你同意后，它会完成创建。还没有想法时，在新建 Agent 时选择「还没想好？先聊聊」。It asks a few questions, then proposes a setup: what data to keep, what to connect, what goes on its dashboard and how it works with your other agents. Approve it and the agent is built. Not sure yet? When you add an agent, choose Not sure yet? Talk it through.

07

只安装世界树Install only the memory tree

不安装完整的 OpenMousse，也可以单独安装世界树，让你常用的 AI 共用同一份记忆。需要 Python 3.11 或更高版本：You can install the memory tree on its own, without the rest of OpenMousse, so the AIs you already use share one memory. It needs Python 3.11 or newer:

pipx install "git+https://github.com/openmousse/openmousse#subdirectory=tree"
mousse-tree init --lang zh
mousse-tree install-service
pipx install "git+https://github.com/openmousse/openmousse#subdirectory=tree"
mousse-tree init --lang en
mousse-tree install-service

世界树默认只在本机的 127.0.0.1:8787 监听；install-service 会让它开机启动（Linux 与 WSL 使用 systemd，macOS 使用 launchd）。接入各个 AI 平台、开放公网地址与改用 Markdown 笔记存储，见世界树的说明。The tree listens only on 127.0.0.1:8787 by default; install-service starts it at boot (systemd on Linux and WSL, launchd on macOS). Connecting each AI platform, giving it a public address and storing memories as Markdown notes are covered in the memory tree README.

常见问题FAQ

出现问题时Something isn’t working

在服务器上运行自检。它会逐项检查服务、手机能否访问、你的 claw 与模型、世界树、每日归档与通知，每项显示 ✓ 或 ✗，并附上修复方法。输出中不含令牌与密钥，可以完整发给协助你的人：Run the self-check on the server. It goes through every piece (the server, reaching it from the phone, your claw and its model, the memory tree, the daily archive and notifications) and prints ✓ or ✗ with the fix for each. Its output contains no tokens or keys, so you can send all of it to whoever is helping you:

bash ~/.openmousse/repo/check.sh

如果安装时还没有这条命令，先重新运行一次安装命令，它会更新到最新版本。Installed before this command existed? Run the install command again first; it pulls the latest version.

手机令牌丢失I lost the phone token

在服务器上生成一个新的令牌。新令牌同样只显示一次：Create a new one on the server. It is also shown only once:

~/.openmousse/venv/bin/python ~/.openmousse/repo/server/tokens.py add phone2
app 无法连接The app can’t connect

依次检查三项：服务器与手机上的 Tailscale 都已开启，并登录同一个账号；app 中填写的是安装程序最后显示的地址（形如 http://100.…:8080，而不是 127.0.0.1）；服务正在运行：Check three things: Tailscale is on and signed in to the same account on both the server and the phone; the address in the app is the one the installer printed (http://100.…:8080, not 127.0.0.1); and the server is running:

Linux · WSLsystemctl --user status openmousse-server，日志：journalctl --user -u openmousse-server -fsystemctl --user status openmousse-server; logs: journalctl --user -u openmousse-server -f
macOSlaunchctl print gui/$(id -u)/ai.openmousse.server，日志：tail -f ~/.openmousse/logs/server.loglaunchctl print gui/$(id -u)/ai.openmousse.server; logs: tail -f ~/.openmousse/logs/server.log
安装时提示缺少 venvThe installer says venv is missing

Ubuntu 与 Debian（包括 WSL）需要单独安装，之后重新运行安装命令：On Ubuntu and Debian (WSL included), install it, then run the install command again:

sudo apt install python3-venv
保持服务一直运行Keeping the server running
Linux退出登录后服务仍需运行时，执行一次 sudo loginctl enable-linger $USER（安装程序会尝试自动开启）。To keep it running after you log out, run sudo loginctl enable-linger $USER once (the installer tries this for you).
macOS服务随你的账号登录启动，并在后台保持运行。在「系统设置」中关闭自动睡眠。The server starts when you log in and keeps running in the background. Turn off automatic sleep in System Settings.
WindowsWSL 不会随 Windows 自动启动：开机后打开一次 Ubuntu 终端，或在「任务计划程序」中添加登录时运行 wsl.exe -d Ubuntu --exec true 的任务。WSL doesn’t start with Windows on its own: open the Ubuntu terminal once after startup, or add a Task Scheduler task that runs wsl.exe -d Ubuntu --exec true at logon.
如何更新How do I update?

重新运行安装命令。它会拉取最新代码、补齐缺少的部分并重启服务；你的数据保持不变。Run the install command again. It pulls the latest code, fills in anything missing and restarts the server. Your data stays as it is.

能否更换模型Can I change the model?

可以。每个对话都能在右上角单独选择模型；默认模型与回退顺序在 OpenClaw 中设置，app 的「我 → 模型与计费」中可以查看当前使用的模型。Yes. Each chat can use its own model (top right of the chat). The default model and the fallback order are set in OpenClaw; Me → Models & billing in the app shows what is in use.

数据存放在哪里Where is my data?

都在你的服务器上：app 的数据在 ~/.openmousse/data，世界树在 ~/.mousse-tree，每个 Agent 的记忆在它的 OpenClaw 工作区中。哪些数据会离开你的服务器、原因是什么，见隐私政策。On your server: the app’s data in ~/.openmousse/data, the memory tree in ~/.mousse-tree, and each agent’s memory in its OpenClaw workspace. What leaves your server, and why, is in the privacy policy.

能否在浏览器中使用Can I use it in a browser?

可以。网页版需要在服务器上构建一次（需要 Node.js）：在 ~/openmousse/app 中运行 npm install && npm run web:build，之后在浏览器中打开服务器地址即可。Yes. The web app needs to be built once on the server (Node.js required): in ~/openmousse/app, run npm install && npm run web:build, then open the server address in a browser.

如何申请 app 或托管服务器How do I get the app or a hosted server?

发送邮件至 hello@openmousse.ai，注明你需要的是 app（iOS 或 Android）还是托管服务器；也可以在 GitHub Discussions 留言。Email hello@openmousse.ai and say whether you need the app (iOS or Android) or a hosted server, or leave a message in GitHub Discussions.
