Getting started新手指南

From zero to your first message on your phone从零开始，到在手机上跟它说第一句话

OpenMousse starts empty: there are no preset Agents, and it builds whatever you ask for. Work through the six steps below, one at a time. OpenMousse 一开始是空的：没有预设的 Agent，你说要什么，它就建什么。按下面六步走，每一步做完再往下。

1

What you need准备好这几样

  • A Linux machine that stays on一台一直开着的 Linux 机器A small box at home or a VPS. Ubuntu or Debian is easiest; it needs systemd, git and Python 3.11 or newer.家里的小主机或者一台 VPS 都行。Ubuntu / Debian 最省事，要有 systemd、git 和 Python 3.11 以上。
  • A claw, set up装好一个 clawOpenClaw does the most: openclaw onboard done, the Gateway running, a model configured on your own account (a Claude or ChatGPT subscription, or an API key). openclaw.ai → Hermes Agent, nanobot, Letta Code or any agent with an OpenAI-compatible chat API work too, with its API turned on; background tasks, approvals and scheduled jobs are OpenClaw-only.OpenClaw 功能最全：跑过 openclaw onboard，Gateway 在跑，模型用你自己的账号配好了（Claude 或 ChatGPT 的订阅，或者 API key）。openclaw.ai → Hermes Agent、nanobot、Letta Code，或者任何有 OpenAI 兼容对话接口的 agent 也行，把它的接口打开；后台任务、执行审批、定时任务只有 OpenClaw 有。
  • An iPhone一部 iPhoneThe app runs there and gets notifications when your Agents have something for you.app 装在上面，Agent 有事会推送到这里。
  • A Tailscale account一个 Tailscale 账号Free. It lets your phone reach the server from anywhere without opening it to the internet. tailscale.com →免费。手机在哪都能连上你的服务器，又不用把服务器暴露到公网。tailscale.com →
2

Install the server装服务

On the server, run:在服务器上跑这一条：

curl -fsSL https://openmousse.ai/install | bash

It asks four questions: language, your claw (Enter for OpenClaw, then the folder with openclaw.json, usually ~/.openclaw; or hermes, nanobot, letta, or another agent's OpenAI-compatible URL), your time zone, and what to call the assistant. Then it sets up the server, the memory tree and the nightly digest, and adds a few rules and skills to your OpenClaw. It backs up openclaw.json before changing it, checks it afterwards, and restarts the Gateway (or tells you to).它会问四个问题：语言、你的 claw（回车 = OpenClaw，再问有 openclaw.json 的那个文件夹，一般是 ~/.openclaw；也可以答 hermes、nanobot、letta，或者填别的 agent 的 OpenAI 兼容接口地址）、你的时区、助手叫什么。然后装好服务、世界树和每晚的日结，给你的 OpenClaw 加上几条规矩和 skill。改 openclaw.json 之前先备份，改完检查一遍，再重启 Gateway（重启不了会提示你）。

Then two more you can skip with Enter: an Obsidian vault folder that's already syncing to this server (the memory tree goes into it as notes, one per memory), and whether to open up public HTTPS through Tailscale Funnel: your other AIs (Claude, ChatGPT…) can then reach the memory tree, your shares get links, and friends can add you. No Tailscale yet? Skip it, and answer y when you run the command again in step 3.接着还有两个，直接回车就跳过：服务器上已经在同步的 Obsidian 库文件夹（世界树会放进去，一条记忆一篇笔记），以及开不开公网（经 Tailscale Funnel）：开了你别的 AI（Claude、ChatGPT……）能连世界树，分享能发链接，能加朋友。还没装 Tailscale 就先跳过，第 3 步重跑安装命令时再答 y。

At the end it prints the server address and a phone token, shown only once. Copy it somewhere; you'll need it in step 4.最后会打印服务地址和一个手机令牌，只显示这一次。先复制下来，第 4 步要用。
3

Reach it from your phone让手机连得上

Unless the machine is already on Tailscale, the server only listens on the machine itself at first. The easiest way in is Tailscale:机器还没在 Tailscale 里的话，服务一开始只听本机，外面连不上。最省事的是 Tailscale：

  1. Install Tailscale on the server and sign in:服务器上装 Tailscale，登录： 
    curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up
  2. On the iPhone, install Tailscale from the App Store and sign in with the same account.iPhone 上从 App Store 装 Tailscale，登同一个账号。
  3. Run the install command from step 2 again. It moves the server onto the Tailscale address and tells you what to enter in the app, something like http://100.x.y.z:8080.再跑一遍第 2 步的安装命令。它会改成听 Tailscale 地址，并告诉你 app 里填什么，像 http://100.x.y.z:8080 这样。

If the server was already on Tailscale in step 2, the installer used that address straight away and only the phone side is left. Rather not use Tailscale? Put 127.0.0.1:8080 behind HTTPS with Caddy, nginx or tailscale serve, and enter that address in the app.第 2 步时服务器已经在 Tailscale 里的话，安装器直接就用了这个地址，只剩手机那一头。不想用 Tailscale：用 Caddy、nginx 或 tailscale serve 把 127.0.0.1:8080 反代成 HTTPS，app 里填那个地址。

4

Install the app and connect装 app，连上

  1. Install OpenMousse with TestFlight. The public link goes here when it opens; until then, ask for an invite in GitHub Discussions. You can also build app/ yourself (it needs an Apple developer account).用 TestFlight 装 OpenMousse。公开测试链接开放后放在这里；在那之前，到 GitHub Discussions 留言要邀请。也可以自己构建 app/（要 Apple 开发者账号）。
  2. Open the app and sign in with your email (it sends a 6-digit code). On the connect screen, enter the Server address from step 3 and, as the Access token, the phone token from step 2.打开 app，先用邮箱登录（收一个 6 位验证码）。再在连接页填服务器地址（第 3 步给的）和接入令牌（第 2 步的手机令牌）。
  3. Allow notifications. Your Agents come to you when something changes.允许通知。Agent 看到变化会来找你。
5

Bring your data in把你的数据带进来

At first it knows nothing about you. Each of these helps it catch up. Skip any of them and come back later.它一开始对你一无所知。下面几样能让它快点认识你，每一样都能跳过、以后再做。

Move your memories from other AIs从别的 AI 搬记忆

Send this to ChatGPT, Claude and Gemini, then paste each answer into the main chat. It files what it learns into your memory tree, which you can review and prune under Me → Memory tree.在 ChatGPT、Claude、Gemini 里各发一次下面这段话，把回答整段贴到主对话里。它会整理进你的世界树，在「我 → 世界树」里能看、能删。

List everything you remember about me, one item per line: my background, what I'm working on, my habits and preferences, and decisions I've made. Facts only, no commentary.
把你记得的关于我的事，逐条列出来：我的背景、在做的事、习惯和偏好、定过的决定。只列事实，不要评价。

Let it interview you让它问你

In the main chat, say “Ask me a few questions to get to know me.” It asks a few at a time and remembers your answers.在主对话里说「问我几个问题，认识一下我」。它一次问几个，你答完它就记下来。

Apple HealthApple 健康

Once connected, the app asks to read Apple Health. Allow it and the first sync reads back a year: sleep, heart rate, steps, workouts and more. Sleep reports and the recovery score come from here. Say no and everything else still works.连上以后，app 会请你授权读取 Apple 健康。允许的话，第一次同步往回读一年：睡眠、心率、步数、训练等等，睡眠报告和恢复分就从这里算。不允许也能用，只是这几样没有数据。

Files文件

PDFs, Word files, spreadsheets, slides and photos: send them in the chat and it reads them.PDF、Word、表格、PPT、照片，在对话里直接发，它会读。

Let your other AIs share this memory让你别的 AI 也用这份记忆

Claude, ChatGPT, Gemini, DeepSeek, Qwen, Kimi: anything that speaks MCP can connect to your memory tree. In the app, open Me → Memory tree → Connect your AI. Each AI gets its own address and a few steps; paste the one-line instruction into its custom instructions and it reads the tree before answering and writes back what you tell it about yourself. Whatever you mention in one of them, the others know too.Claude、ChatGPT、Gemini、DeepSeek、通义千问、Kimi，支持 MCP 的都能接到你的世界树。在 app 里打开「我 → 世界树 → 接到你的 AI」：每个 AI 一个地址，照着几步接上，再把那一句指令贴进它的自定义指令。之后它回答前会先读这棵树，你说起自己的新事它会写回来；在哪边说过的，别的都知道。

These apps connect from their own clouds, so the tree needs a public HTTPS address first: answer yes when the installer asks, or follow the steps the app shows.它们是从自己的云来连的，所以世界树先要有一个公网 HTTPS 地址：安装时问到就回答要，或者照 app 里的提示开。

Later, each time you build an Agent, it first tells you what data that Agent will keep and where it comes from.之后每建一个 Agent，它都会先告诉你这个 Agent 要记哪些数据、从哪来。

6

Say the first thing跟它说第一件事

There are no preset Agents. In the main chat, say what you want looked after, for example:这里没有预设的 Agent。在主对话里说一句你想让它管什么，比如：

Help me sleep betterI'm preparing for the GRETrack my spendingKeep an eye on my visa paperwork
帮我把睡眠调好我在准备 GRE帮我记账盯着我的签证材料

It asks a few questions, then proposes a setup: what data to keep, what to connect, what goes on its dashboard, and how it works with your other Agents. Say yes and it's built. Not sure yet? When you add an Agent, tap “Not sure yet? Talk it through”.它会先问几个问题，再给你一份方案：记哪些数据、接哪些渠道、看板放什么、和别的 Agent 怎么配合。你点同意，它就建好。还没想好？新建 Agent 时点「还没想好？先聊聊」。

FAQ常见问题

Something isn't working哪里不对劲

Run the self-check on the server. It goes through every piece (the server, reaching it from the phone, your claw and its model, the memory tree, the nightly digest, notifications) and prints ✓ or ✗ with the command that fixes each one. There are no tokens or keys in its output, so you can send all of it to whoever is helping you:在服务器上跑一下自检。它把每一块都查一遍（服务、手机连不连得上、你的 claw 和模型、世界树、每晚的日结、推送），打出 ✓ 或 ✗，每条后面写怎么修。输出里没有令牌和密钥，可以整段发给帮你的人：

bash ~/.openmousse/repo/check.sh

Installed before this command existed? Run the install command again first; it pulls the latest version.装的时候还没有这个命令的话，先再跑一遍安装命令，它会拉到最新的。

I lost the phone token手机令牌丢了

Make a new one on the server. It is also shown only once:在服务器上生成一个新的，同样只显示一次：

~/.openmousse/venv/bin/python ~/.openmousse/repo/server/tokens.py add phone2
The app can't connectapp 连不上

Check three things: Tailscale is on and signed in to the same account on both the server and the phone; the address in the app is the one the installer printed (http://100.…:8080, not 127.0.0.1); and the server is running:看三样：服务器和手机上的 Tailscale 都开着、登的是同一个账号；app 里填的是安装器最后给的地址（http://100.…:8080，不是 127.0.0.1）；服务在跑：

systemctl --user status openmousse-server
journalctl --user -u openmousse-server -f
The installer says venv is missing安装时说缺 venv

On Ubuntu or Debian, install it and run the install command again:Ubuntu / Debian 上装一下，再跑一遍安装命令：

sudo apt install python3-venv
The server stops when I log out一登出，服务就停了

Let your user services keep running after you log out (the installer tries this and tells you if it couldn't):让你的用户服务在登出后继续跑（安装器会试着开，开不了会提示）：

sudo loginctl enable-linger $USER
How do I update?怎么更新

Run the install command again. It pulls the latest code, fills in anything missing and restarts the server. Your data stays as it is.再跑一遍安装命令。它会拉最新的代码、补上缺的，再重启服务；你的数据不动。

Can I change the model?能换模型吗

Yes. Each chat can use its own model (top right of the chat). The default model and the fallback order live in OpenClaw; Me → Models & billing in the app shows what's in use.能。每个对话右上角能单独换；默认模型和回退顺序在 OpenClaw 里配，app 里「我 → 模型与计费」能看到现在用的是什么。

Where is my data?数据存在哪

On your server: the app's data in ~/.openmousse/data, the memory tree in ~/.mousse-tree, and each Agent's memory in its OpenClaw workspace. What leaves your machine, and why, is in the privacy policy.都在你的服务器上：app 的数据在 ~/.openmousse/data，世界树在 ~/.mousse-tree，每个 Agent 的记忆在它的 OpenClaw 工作区里。哪些会离开你的机器、为什么，见隐私政策。

Can ChatGPT, DeepSeek and the rest use the same memory?能让 ChatGPT、DeepSeek 这些也用同一份记忆吗

Yes, any AI that speaks MCP, through the memory tree. The app walks you through it under Me → Memory tree → Connect your AI; when an app's web version can't add custom MCP servers yet (Qwen, Kimi), use its command-line tool (Qwen Code, Kimi Code) or any MCP client set up with its model. Details are in the memory tree README.能，支持 MCP 的都行，靠世界树。app 里「我 → 世界树 → 接到你的 AI」会一步步带你接；网页版还不能加自定义 MCP 的（通义千问、Kimi），用它家的命令行工具（Qwen Code、Kimi Code），或者任何支持 MCP 的客户端配上它的模型。细节见世界树的说明。
